# 利息、叽米与主角光环修复（2026-10-13）

## 行为变化

| 项目 | 修复 |
| --- | --- |
| 开源节流（300101） | 结算原本使用上限 9，但基础信息仍发送默认上限 5。两处现在共用 `CurrentMaxInterestGold`，上限变化时发送完整基础信息。85 金对应利息 8，90 金起为 9；未花金币的额外奖励保持原逻辑。 |

| 星徽大使叽米（303301） | 新增 NPC 902，携带 3 件锁定的财富宝钻；选择时发放 9 枚同种随机星徽，不逐节点重复发放。 |

| 纳米改件（100101） | 战斗装备列表中，持有者第一件符合升级表的进阶装备临时换成特权版本。不改变背包、实例 ID 或备战装备；无符合条件的装备时不生成装备。 |
| 刷新视界·进阶（100106） | 补齐此前遗漏的进阶版。持有者参与上场战斗后，进入新节点得到 1 次免费刷新；手动刷新商店每次累加 2% 前/后台强度。免费刷新计数，自动铺店不计数。普通版保持 1.5%，两者分别保存次数。 |

叽米 NPC、携带装备与领取进度随对局保存。旧存档已经选中叽米但没有 NPC 时，恢复时补建并补发一次；再次恢复不重复发奖。背场增加一个格子，仍受 9 格总上限约束。

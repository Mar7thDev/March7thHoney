# 阿哈装备与空白说明（2026-10-13）

## 装备显示

用户截图是欢愉羁绊的阿哈详情。该面板读取 `EquipComponent.GetSlotEquipItemData`，与玩家购买的151102等阿哈角色的普通装备列表不同。

日志确认初始简易装备已经抽取。例如本局为350207、350202、350202。此前局外 `JHCEEAPHHGK` 仅在字段1下发预设装备，字段5下发库存唯一号；尚未合成时唯一号为0，因此当前装备为空，合成后也可能将库存号当作配置号。

现在字段5下发当前装备的配置ID：未合成用预设ID，合成后用进阶装备ID。库存唯一号仍只在服务器内部记录，不复制装备到背包、不改变羁绊解锁门槛和战斗数值。

`ElationUiRegression` 覆盖初始3个槽位、解锁状态、无额外发奖、简易装备合成、配置ID与库存号区分、局外/战斗一致性及恢复存档。全量回归396/396通过；Release构建0警告、0错误。

## 空白说明

在已登录游戏的聊天命令入口执行：

```text
/windy load gridfight_aha_text.lua
```

随后关闭并重新打开阿哈面板。脚本不需要重启服务器，但它只影响当前客户端进程；重新启动游戏后需再次加载。没有加入全服自动执行列表。退出客户端即可清除此次内存中的界面补丁。

说明依据本地 `GFTraitElationTemplate` 的3件初始简易装备、羁绊3/4/6层解锁1/2/3个槽位，以及现有合成实现。玩法背景可参见 [BWIKI 欢愉羁绊](https://wiki.biligame.com/sr/%E8%B4%A7%E5%B8%81%E6%88%98%E4%BA%89/%E7%BE%81%E7%BB%8A/%E6%AC%A2%E6%84%89)。
